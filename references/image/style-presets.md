# Image Style Presets (12)

> Used by `image-prompt-designer` skill to choose visual style per article format.

## 1. editorial-photography
**Best for**: listicle / review / news-analysis / case-study
**Keywords**: National Geographic 2026, editorial documentary, photojournalism, candid, authentic
**Avoid**: stock photo, over-polished, posed

## 2. product-photography
**Best for**: product-review / comparison / shortlist-validation
**Keywords**: studio lighting, high-key, isolated subject, gradient background, premium
**Avoid**: cluttered context, lifestyle distractions

## 3. lifestyle-photography
**Best for**: personal-story / opinion / interview / brand-story
**Keywords**: natural light, candid environmental, real moments, slice-of-life
**Avoid**: studio sterility, posed compositions

## 4. flat-illustration
**Best for**: how-to-guide / definition / encyclopedic / glossary-hub
**Keywords**: clean lines, limited palette (3-5 colors), vector style, geometric
**Avoid**: photorealistic shadows, gradients, 3D

## 5. isometric-illustration
**Best for**: how-to-guide / data-research / technical
**Keywords**: 30° axonometric, technical diagram, infographic, schematic, blueprint
**Avoid**: front-facing perspective, photorealism

## 6. 3d-render
**Best for**: case-study / data-research / technical / product-review
**Keywords**: photorealistic 3D, depth, realistic lighting, octane render, ray tracing
**Avoid**: cartoon style, low-poly look

## 7. infographic-style
**Best for**: data-research / comparison / news-analysis / trend-post
**Keywords**: charts and icons, minimal text, data viz, color-coded zones
**Avoid**: photo content, complex scenes

## 8. documentary-style
**Best for**: case-study / interview / personal-story / brand-story
**Keywords**: behind-the-scenes, authentic, raw, unposed, available light
**Avoid**: studio polish, dramatic lighting

## 9. conceptual-photography
**Best for**: opinion / thought-leadership / philosophical content
**Keywords**: metaphorical, abstract, artistic, thought-provoking, surreal hint
**Avoid**: literal interpretation

## 10. vintage-film
**Best for**: personal-story / brand-story / nostalgic content
**Keywords**: 35mm film grain, warm tones, faded highlights, slight color shift
**Avoid**: digital crispness, modern aesthetic

## 11. minimalist
**Best for**: template-resource / curated-roundup / clean tutorial
**Keywords**: lots of white space, single subject, minimal composition, clean
**Avoid**: busy backgrounds, multiple subjects

## 12. dramatic-style
**Best for**: news-analysis / breakthrough announcements / launch posts
**Keywords**: high contrast, deep shadows, dynamic angle, motion, energy
**Avoid**: flat lighting, static composition
