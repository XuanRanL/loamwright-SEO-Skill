# Spelling: en-NZ

New Zealand English. Follows UK + Australian spelling with Māori-influenced vocabulary.

## Spelling: 95% identical to en-UK / en-AU

Use `references/localization/spelling/en-UK.md` for the master pair list. Same forms:
- colour, organise, customise, realise, analyse, optimise
- centre, metre, litre, defence, honour
- catalogue, dialogue, travelling, tyre, aluminium

## NZ-specific vocabulary

| NZ | US/UK equivalent |
|---|---|
| jandals | flip-flops (NZ has neither "thongs" nor "sandals" for this) |
| chilly bin | cooler (AU: "esky") |
| tramping | hiking (long walks in nature) |
| dairy | corner shop (small convenience store) |
| bach | small holiday house (pronounced "batch") |
| togs | swimsuit |
| chocka | full (slang) |
| sweet as | great / awesome (slang) |
| no worries | OK / it's fine |

## Māori loanwords (use with respect)

NZ English incorporates many Māori words. Use accurately:

| Māori | Meaning | When to use |
|---|---|---|
| Kia ora | hello / thanks | greetings; common in casual + business |
| Aotearoa | New Zealand | poetic / cultural context |
| Whānau | extended family | formal cultural reference |
| Tangata whenua | indigenous people | respectful cultural reference |
| Mana | prestige / authority | informal use OK |
| Iwi | tribe | tribal reference (use carefully) |
| Marae | meeting place | location reference |

For B2C content: occasional Māori words signal NZ identity. For B2B: minimize unless culturally relevant.

## Numbers + units

- Currency: `NZ$1,234.56` or `$1,234.56` (when context clear)
- Distance: kilometres (km). Never miles.
- Weight: kilograms (kg). Never pounds.
- Temperature: °C
- Date format: `19 May 2026` or `19/05/2026` (DD/MM/YYYY)
- Phone: `+64 9 1234 5678` or `(09) 1234 5678`

## Punctuation

- Same as UK / AU
- Em-dashes: zero tolerance per P13

## Tone defaults

- "She'll be right" attitude (relaxed)
- Self-deprecating humour
- "Kia ora" or "Hi team" as informal openers
- Less formal than UK; less direct than US

## Regulatory references

- Commerce Commission — advertising + disclosure
- Medsafe — health/medical
- FMA (Financial Markets Authority) — financial
- Broadcasting Standards Authority
