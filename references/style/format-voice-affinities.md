# Format × Voice Affinities

Some format-voice combinations are natural fits; others feel forced. This table maps each of the 24 formats to its **best**, **good**, **awkward**, and **avoid** voice pairings.

**Important**: brand-guideline voice ALWAYS wins. This table is **suggestion only** — if the brand voice clashes with format affinity, the system surfaces a warning, but does NOT override.

## Affinity legend

```
✓✓ Natural fit (canonical pairing)
✓  Good fit (works well)
⚠  Awkward (works but feels forced)
✗  Avoid (substantial mismatch)
```

## How format-selector uses this

When user runs `/article "keyword"`:

```
1. format-selector picks format based on keyword + intent
   (e.g., "best CRM 2026" → listicle)

2. Check current brand voice (from brand-guideline.yaml)
   (e.g., voice=technical)

3. Look up affinity in this table
   (listicle × technical → ✓ Good fit)

4. If ✓✓ or ✓: proceed silently
   If ⚠: surface warning to user
   If ✗: STRONG warning + suggest changing voice OR changing format
```

## Override behavior

The brand-guideline voice ALWAYS wins. This table is suggestion only.

Example:
- Brand voice = `nussbaum-academic`
- Format selected = `shortlist-validation`
- Affinity = ✗ (mismatch)

System action:
```
⚠ Format-Voice Mismatch
Your brand voice (nussbaum-academic) is a poor fit for shortlist-validation
format. The format expects ≤10 word sentences; nussbaum-academic prose
typically runs 22-30 words.

Options:
A) Continue with nussbaum-academic + adapt format expectations
B) Use casual or blunt voice for THIS article only
C) Pick different format (listicle / comparison)
```

User decides.

## Per-vertical caveat

Some affinities differ by vertical. For example:
- `product-review + luxury` is ✓✓ for jewelry/watches; ✗ for tech gadgets
- `case-study + inspirational` is ✓ for fitness; ✗ for B2B enterprise

When brand-guideline industry is set, the system can apply industry-specific overrides to this base table.
